# 春秋战国历史地图展示

## 项目概述

一个科普宣传风格的交互式网页，展示春秋战国时期（公元前770年-公元前221年）的历史变迁。

## 时间范围

- **起点**：烽火戏诸侯（约公元前771年）
- **终点**：秦始皇统一六国（公元前221年）

## 核心功能

1. **交互式地图**：展示各诸侯国的疆域变化
2. **时间轴**：关键历史事件的时间线
3. **国家信息**：各国兴衰、重要人物、战役
4. **科普内容**：历史背景介绍

## 技术栈

- HTML5 + CSS3 + JavaScript (原生)
- Canvas 2D 绘图（地图渲染）
- 响应式设计（支持移动端）

## 项目结构

```
warring-states/
```
