# 贪吃蛇游戏

> 经典贪吃蛇游戏的现代化实现

## 📖 简介

这是一个功能完整的贪吃蛇游戏，支持多种控制方式和难度设置：

- 经典贪吃蛇玩法
- 多种控制方式（键盘/触摸/手势）
- 分数和最高分记录
- 游戏暂停/重新开始

## 🛠️ 技术栈

- **HTML5 Canvas** - 游戏渲染
- **CSS3** - 界面样式
- **原生 JavaScript** - 游戏逻辑
- **localStorage** - 最高分存储

## ✨ 功能特性

| 功能 | 描述 |
|------|------|
| 多种控制 | 键盘方向键/WASD/虚拟按键/手势 |
| 移动端支持 | 触摸滑动控制 |
| 分数系统 | 当前分数 + 最高分记录 |
| 游戏状态 | 开始/暂停/游戏结束 |
| 响应式设计 | 适配不同屏幕尺寸 |

## 🎮 操作说明

### 桌面端
- **方向键** / **WASD** - 控制蛇移动
- **空格键** - 暂停/继续

### 移动端
- **虚拟按键** - 点击方向按钮
- **滑动屏幕** - 手势控制方向
