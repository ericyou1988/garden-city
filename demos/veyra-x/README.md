# 🏎️ Veyra X — 电动超跑发布网站

> 虚构的未来电动超跑「Veyra X」发布网站。一辆在暗房中被扫光照亮的流线型概念车,
> 随滚动完成 360° 环绕展示并冲入霓虹隧道,最后在实时配置器中改变漆面与轮毂。

---

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🏎️ **程序化超跑** | 超椭圆截面放样构建流线低趴车身 + 玻璃顶盖,后翼/尾灯/发光裙边/涡轮轮毂,零外部模型 |
| 💡 **电影级灯光** | 扫光主灯 + 体积光束 + 青色/洋红轮廓光 + PMREM 环境反射(亮面漆 clearcoat) |
| 🌊 **液态玻璃 UI** | 导航/按钮/状态卡/配置器/预约表单全部采用 Apple 风格液态玻璃(边缘折射 + 高光 + 悬停液体响应) |
| 🎬 **滚动编排** | 相机随滚动环绕展示不同角度 → 车冲进霓虹隧道(灯环流光 + 运动模糊速度感)→ 转盘展示 |
| 📊 **性能数据** | 0-60、极速、续航、峰值功率,进入视口时数字滚动计数动画 |
| 🔦 **部件高亮** | 设计区选择部件(玻璃顶盖/灯带/轮毂/裙边/碳纤单体壳),3D 车上高亮发光 + 跟随标签 |
| 🎨 **实时配置器** | 6 色漆面 / 亮面·哑光 / 3 种轮毂,3D 模型即时响应 + 价格联动 |

---

## 🎮 操作指南

| 操作 | 效果 |
|------|------|
| **滚动** | 推进剧情:环绕展示 → 隧道冲刺 → 配置器 |
| **移动鼠标** | 相机视差 + 灯光随动,玻璃高光跟随光标 |
| **点击部件标签** | 在设计区高亮对应 3D 部件 |
| **配置器点击** | 实时更换漆面颜色 / 光泽 / 轮毂样式 |
| **预约表单** | 提交后显示成功态(纯前端演示) |

## 🔧 技术栈

- **Three.js 0.160**(jsdelivr CDN,importmap + ES Module)
- **GSAP 3.12 + ScrollTrigger**(滚动驱动相机编排)
- **EffectComposer + UnrealBloomPass**(灯带辉光)
- **PMREMGenerator**(程序化摄影棚环境反射)
- **原生 JS / CSS**(无构建步骤,无外部图片模型)

| 环节 | 说明 |
|------|------|
