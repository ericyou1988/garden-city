# 天气应用

> 基于 Open-Meteo API 的实时天气查询应用

## 📖 简介

这是一个功能完整的天气查询应用，支持：

- 城市搜索和自动补全
- 实时天气数据显示
- 小时级天气预报
- 7 天天气预报
- 动态背景粒子动画

## 🛠️ 技术栈

- **HTML5/CSS3** - 界面结构
- **原生 JavaScript** - 业务逻辑
- **Open-Meteo API** - 天气数据源（免费，无需 API Key）
- **Canvas** - 动态背景粒子

## ✨ 功能特性

| 功能 | 描述 |
|------|------|
| 城市搜索 | 支持全球城市搜索 |
| 实时天气 | 温度、湿度、风速、气压 |
| 小时预报 | 24 小时逐小时预报 |
| 7 天预报 | 未来一周天气趋势 |
| 动态背景 | 粒子动画效果 |
| 响应式设计 | 适配桌面和移动端 |

## 📊 数据来源

- **地理编码**: Open-Meteo Geocoding API
- **天气预报**: Open-Meteo Forecast API
