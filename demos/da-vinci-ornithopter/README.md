# 🛸 达芬奇扑翼机 — Three.js 三维机械展示

> 列奥纳多·达·芬奇（1452-1519）在 1485 年左右设计了扑翼机（Ornithopter），
> 这是人类最早的飞行器设计之一。

---

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🛸 **三维模型** | 程序化构建 8 个机械部件（机身、双翼、尾翼、起落架、扑翼机构、尾桨） |
| 🔄 **旋转缩放** | OrbitControls 完整交互（左键旋转 / 滚轮缩放 / 右键平移） |
| 💥 **爆炸图** | 一键分离所有部件，展示内部机械结构，再次点击聚合 |
| 🏷️ **部件高亮** | 鼠标悬停高亮 + 名称悬浮标签，点击部件短暂高亮 |
| 🔲 **线框模式** | 切换线框/实体显示，观察几何结构 |
| 🔄 **自动旋转** | 开始/停止自动旋转展示 |
| ℹ️ **信息面板** | 右侧历史背景面板（达芬奇手稿 + 扑翼原理） |

---

## 🎮 操作指南

| 操作 | 效果 |
|------|------|
| **鼠标左键拖拽** | 旋转视角 |
| **鼠标滚轮** | 缩放 |
| **鼠标右键拖拽** | 平移视角 |
| **点击部件** | 高亮显示 1.5 秒 |
| **右侧面板悬停** | 高亮对应部件 |
| **底部按钮** | 爆炸图 / 自动旋转 / 重置视角 / 线框模式 |

## 🔬 机械结构说明

| 部件 | 说明 |
|------|------|
| 机身骨架 | 细长圆柱 + 环形框架 + 纵向支撑杆 |
| 驾驶舱 | 半透明球罩（模拟玻璃） |
| 左翼 / 右翼 | Shape 翼型 + 翼梁 + 翼肋 |
| 尾翼 | 垂直翼面 + 水平尾翼 |
| 起落架 | 三轮式（前两后一）+ 支撑柱 + 连接杆 |
| 扑翼机构 | 曲柄 + 连杆 + 翼连接点 |
| 尾桨 | 螺旋桨（3 桨叶） |
