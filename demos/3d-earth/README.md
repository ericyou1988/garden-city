# 3D 地球轨道数据中心

> 使用 Three.js 构建的太空数据中心可视化 Demo

## 📖 简介

这是一个展示 3D 地球轨道数据中心的交互可视化 Demo。通过 WebGL 技术，用户可以：

- 旋转查看地球和卫星轨道
- 观察实时数据流传输
- 查看卫星状态和带宽信息

## 🛠️ 技术栈

- **Three.js 0.160.0** - 3D 渲染引擎
- **WebGL** - 图形渲染
- **原生 JavaScript** - 交互逻辑

## ✨ 功能特性

| 功能 | 描述 |
|------|------|
| 3D 地球 | 可交互旋转的地球模型 |
| 卫星轨道 | 多轨道卫星实时运动 |
| 数据流 | 卫星间数据连接可视化 |
| HUD 界面 | 实时显示卫星数量、带宽等信息 |
| 控制面板 | 自动旋转、数据流、标签切换 |

## 🎮 交互操作

- **拖拽** - 旋转视角
- **滚轮** - 缩放
- **点击卫星** - 查看详细信息
