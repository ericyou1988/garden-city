# Demo 模板

这是一个 Demo 模板目录，您可以基于此模板创建自己的 Demo。

## 使用方法

1. 复制此模板目录
2. 重命名为您的 Demo 名称（使用 kebab-case，例如：`my-awesome-demo`）
3. 修改 `index.html` 中的标题和内容
4. 根据需要修改 `style.css` 和 `script.js`
5. 添加您需要的其他资源文件

## 文件说明

- `index.html`：主入口文件，包含基本的 HTML 结构
- `style.css`：样式文件，包含基础样式和响应式设计
- `script.js`：脚本文件，包含简单的交互示例

## 注意事项

- 所有资源文件使用相对路径引用
- 保持代码简洁可读
- 添加必要的注释
- 确保在不同设备上都能正常显示
